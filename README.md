# TAMY — تطبيق الأذكار

تطبيق أذكار كامل: أذكار الصباح والمساء والنوم والاستيقاظ وبعد الصلاة، حصن المسلم، الرقية، أدعية قرآنية، المسبحة، مواقيت الصلاة، اتجاه القبلة، أسماء الله الحسنى، وتنبيهات للأذكار والصلاة.

## كيف تطلّع الـ APK من Termux

بناء الأندرويد نفسه (Gradle + Android SDK) ثقيل جدًا ومش مضمون جوّه Termux، فالطريقة المضمونة:
**ترفع المشروع من Termux إلى GitHub، وGitHub يبني الـ APK لك مجانًا ويديك رابط تحميل.**

### 1) جهّز Termux (مرة واحدة)
```bash
pkg update -y && pkg install -y unzip git gh
termux-setup-storage
```

### 2) فكّ المشروع
حط ملف `tamy.zip` في مجلد التنزيلات، ثم:
```bash
cd ~
unzip ~/storage/downloads/tamy.zip
cd tamy
```

### 3) ارفعه على GitHub
```bash
bash scripts/termux-push.sh
```
السكربت هيطلب منك تسجيل الدخول لحساب GitHub (لازم يكون عندك حساب مجاني)، وبعدها يرفع المشروع تلقائيًا.

### 4) حمّل الـ APK
- افتح المستودع `tamy-app` على GitHub من المتصفح.
- تبويب **Actions** ← انتظر حوالي 6–10 دقائق حتى يظهر علامة ✓ خضراء.
- تبويب **Releases** ← حمّل الملف **TAMY.apk** وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

أي تعديل بعد كده: غيّر الملفات ثم `git add -A && git commit -m "update" && git push` وهيتبني APK جديد. التوقيع ثابت، فالنسخة الجديدة تتثبت فوق القديمة بدون حذف.

## القرآن الكريم
- المصحف كاملًا بالترتيب (114 سورة) من تبويب **القرآن**: فهرس السور، فهرس الأجزاء، بحث بالاسم أو الرقم، علامات مرجعية، ومتابعة القراءة من آخر موضع.
- نص المصحف **لا يُكتب يدويًا**: يُجلب أثناء البناء على GitHub من حزمة `quran-json` (النص العثماني)، ويتحقق `scripts/fetch-quran.js` من العدد (114 سورة / 6236 آية). إن لم يتطابق العدد يفشل البناء بدل أن يخرج مصحف ناقص.
- اضغط على أي آية لتنسخها أو تشاركها أو تضع عليها علامة.
- لو فشلت خطوة «Prepare Quran text» على GitHub يُبنى التطبيق بدون المصحف ويظهر تحذير في صفحة البناء؛ ابعت نص الخطأ ليُصلح.

## الأذان
1. ضع ملف الأذان في `assets/audio/adhan.mp3` (وللفجر اختياريًا `adhan_fajr.mp3`). التفاصيل في `assets/audio/README.txt`.
2. ارفع التعديل على GitHub (`git add -A && git commit -m "adhan" && git push`).
3. بعد التثبيت: الإعدادات ← فعّل «الأذان بصوت المؤذن» ← جرّب «تجربة الأذان كإشعار».

ملاحظات:
- صوت الأذان عند إغلاق التطبيق هو مقطع 40 ثانية (حدّ صوت الإشعارات في أندرويد). عند فتح التطبيق وقت الصلاة يظهر شريط فيه زر «تشغيل الأذان كاملًا».
- بدون ملف أذان يعمل التطبيق بنغمة الإشعار العادية.
- لو غيّرت ملف الأذان لاحقًا ولم يتغير الصوت على هاتفك: أندرويد يحتفظ بصوت قناة الإشعار، فامسح بيانات التطبيق أو أعد تثبيته.

## تحديث التطبيق على نفس المستودع
```bash
cd ~ && rm -rf tamy_new && mkdir tamy_new && cd tamy_new
unzip "$(ls -t ~/storage/downloads/tamy*.zip | head -1)"   # أحدث ملف تنزيل
cp -rf tamy/. ~/tamy/tamy/
cd ~/tamy/tamy && git add -A && git commit -m "update" && git push
```
رقم نسخة التطبيق يزيد تلقائيًا مع كل بناء، فتثبّت النسخة الجديدة فوق القديمة بدون حذف.

## بعد التثبيت
1. افتح التطبيق ← **الإعدادات** ← اختر مدينتك أو اضغط «تحديد موقعي تلقائيًا».
2. اضغط **«تنبيه تجريبي»** وتأكد إنه وصلك.
3. لو التنبيهات متأخرة: اضغط «تنبيهات دقيقة» وفعّلها، واستثنِ التطبيق من توفير البطارية (خصوصًا هواتف Xiaomi / Oppo / Huawei / Samsung).

## تعديل التطبيق
- `www/data.js` — الأذكار والأدعية.
- `www/quran.js` و`www/surahs.js` — شاشات القرآن وفهرس السور والأجزاء.
- `www/style.css` — الألوان والتصميم.
- `www/app.js` — الشاشات والمنطق.
- `assets/` — الأيقونة (`icon-only.svg` وغيرها) وشاشة البداية. بعد أي تعديل في SVG لازم يتحول لـ PNG بنفس الاسم.
- `capacitor.config.json` — اسم التطبيق والمعرّف (`com.tamy.azkar`).

## ملاحظات
- مواقيت الصلاة تُحسب داخل الجهاز بدون إنترنت (الافتراضي: الهيئة المصرية العامة للمساحة). قارنها بتقويم بلدك واضبط الدقائق من الإعدادات إذا لزم.
- نصوص الأذكار مأخوذة من الكتاب والسنة؛ راجعها قبل نشر التطبيق لغيرك. وراجع نص المصحف المعروض أول مرة مع مصحف مطبوع موثوق.
- ملف `tamy.keystore` هو مفتاح توقيع شخصي للتجربة؛ لو هتنشر التطبيق على Google Play اعمل مفتاح خاص بيك.
